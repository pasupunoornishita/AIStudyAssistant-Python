## 📌 About the Project

AI Study Assistant is an intelligent learning platform that helps students enhance their learning experience using advanced Artificial Intelligence technologies.

The system combines multiple AI APIs to provide:

🧠 Intelligent Question Answering

🎤 Audio Processing & Speech Understanding

🎥 Video Content Analysis

📚 Semantic Search using Embeddings

🛡️ Content Moderation & Safety Checks

📖 Personalized Learning Assistance

The platform enables learners to interact naturally with AI and receive meaningful educational guidance.
